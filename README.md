# interaction-mod

[Cinematic Interactions](https://github.com/) (Fabric 1.21.1, by DyslexicCreate, MIT) patched so the **client alone is enough**:
join any vanilla/other server, the mod opens the real block menu through vanilla packets and shows its cinematic UI on top.

* Original jar: `libs/`. Add-on source: `src/`. `tools/patch_jar.py` overlays the add-on on the original jar.
* Build: GitHub Actions -> Releases -> `latest`.
* Not possible without a server-side mod: campfire scene (disabled), other players seeing your scene, items staying on tables.
